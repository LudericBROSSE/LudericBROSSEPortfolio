Interface Web de Pilotage IoT (Projet Thalès)

Contexte

Projet Thalès d'envergure : Développer une solution complète de pilotage d'objets connectés (IoT) via une interface web sécurisée.

Action

Implémentation de l'architecture serveur-microcontrôleur en assurant un contrôle strict des accès.

  • Contrôle Embarqué : Pilotage de capteurs matériels (Raspberry Pi Pico).
  • Gestion de Permissions : Système d'authentification robuste (Admin/Utilisateur).
  • Interaction : Déclenchement d'actions et remontée de données en temps réel.
  • Administration BDD : Stockage dynamique et consultations sécurisées.

Résultat

Livrable technique complet validant le contrôle d'équipements distants en environnement sécurisé.
